# Governance

TGV begins as a maintainer-led open-source project.

Maintainers set release scope, review contributions, manage security disclosures, and preserve project principles. Decisions should be documented in issues, pull requests, or architecture decision records when they affect public interfaces or trust boundaries.

As the contributor base grows, the project may adopt a multi-maintainer model with documented nomination, voting, and removal procedures. No contributor is entitled to commit access solely by volume of contribution.
